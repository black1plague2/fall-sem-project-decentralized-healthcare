How It Works

1

Upload & Encrypt

Select a medical record. AES-256-GCM encrypts it client-side before it ever reaches the server.

2

IPFS Storage

Encrypted file pinned on IPFS via Pinata. Immutable, censorship-resistant, globally available.

3

Key Wrapping

Wrap the encryption key for each authorized actor using RSA-OAEP. Only they can unwrap it.

4

Multi-Layer Verification

Hydra L2: Fast permission checks (5-15ms) • Aiken L1: Smart contract anchor (~2s) • Midnight ZK: Privacy proofs (800-1200ms) • Blockfrost: Public fallback

5

Access Control

Actors request access. System verifies permissions across layers. Grant or revoke instantly.

6

Audit Trail

Every operation logged with requestId correlation. Full compliance audit trail forever.
